tradeoffs: 'Choosing the rendering mode page by page rather than one for the whole site: static generation for stable content, server rendering for changing data, client rendering for interactive parts. It is more complexity to master, but each page gets the loading behaviour that suits it. On the infrastructure side, Docker and Kubernetes take more setting up, in exchange for automated, reproducible deployments.'
result: 'Close to three years on the product, from January 2023 to October 2025: the React / Next.js site built from the mock-ups, the NestJS APIs, the GitLab and Jenkins pipelines, Kubernetes deployments, VPN-secured access and backups in place.'
